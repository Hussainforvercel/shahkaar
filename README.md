# Shahkaar

> Heritage. Handcrafted. Timeless.

Official coming soon storefront for **Shahkaar** (`shahkaar.store`).

## Tech Stack
- **Framework:** Next.js (App Router, Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the page.

## Build

```bash
npm run build
```
